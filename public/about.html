What is this?

OpenAPI Catalog is an automated service that discovers, converts, and catalogs public OpenAPI specifications from across the web. Every API in the catalog comes with:

  • Bruno collection: ready to download and open in Bruno
  • Endpoint documentation: generated from the spec, with code samples in nine languages
  • Raw OpenAPI document: JSON, at a stable URL for tools and agents
  • Source information: links to the original GitHub repository or official source
  • Categorization: organized into categories for easy discovery

Data sources

Specifications are aggregated from two primary sources.

GitHub scraper

A scraper searches GitHub for public repositories containing OpenAPI specifications (openapi.json, openapi.yaml, swagger.json, and similar). This gives us:

  • Hundreds of APIs from community projects and open-source tools
  • Star counts as a quality signal
  • Direct GitHub links to the source repositories
  • Automatic categorization based on keywords and repository metadata

APIs.guru import

We import the APIs.guru directory, which includes:

  • Thousands of APIs from hundreds of providers
  • Official APIs from AWS, Azure, Google Cloud, Stripe, Twilio, and more
  • Well-maintained specs with regular updates
  • Rich metadata including categories, logos, and provider information

How it works

  1. Discovery: we continuously scan GitHub and sync with APIs.guru
  2. Download: OpenAPI specs are downloaded and validated
  3. Conversion: each spec is converted to a Bruno collection using bruno-doc-gen
  4. Documentation: endpoint documentation is generated from the collection
  5. Cataloging: APIs are tagged, categorized, and made searchable

For agents and tools

Everything on the site is also available as plain text or JSON:

  • GET /llms.txt: short overview with category links and the most popular APIs
  • GET /llms-full.txt: every API, one line each
  • GET /api/apis?search={query}: JSON search with name, tags, provider, endpoint count, and links
  • GET /apis/{slug}/openapi.json: the raw OpenAPI document for any entry
  • GET /api/apis/{id}/download: the Bruno collection as a ZIP

Technology

  • Backend: Node.js and Express
  • Database: SQLite
  • Scraping: GitHub API via Octokit
  • Conversion: bruno-doc-gen (OpenAPI to Bruno)
  • Storage: file system for specs, collections, and docs

Why Bruno?

Bruno is a fast, Git-friendly, open-source API client that stores collections directly in your filesystem. Unlike cloud-based alternatives, Bruno gives you:

  • Full control over your API collections
  • Git-based version control
  • Offline-first functionality
  • Privacy and security (no cloud sync required)

Get started

Browse the catalog, find an API, and use the Collection button to download it as a ZIP. Unzip it and open the folder in Bruno to start sending requests.

Frequently asked questions

What is OpenAPI Catalog?

OpenAPI Catalog is a free, open-source directory of public OpenAPI and Swagger specifications. It collects specs from GitHub repositories and the APIs.guru directory, generates interactive endpoint documentation from each one, and packages every API as a Bruno collection you can open in the Bruno API client.

Where do the API specifications come from?

Specs come from two sources: a scraper that searches public GitHub repositories for openapi.json, openapi.yaml and swagger.json files, and a sync with the APIs.guru directory of official API descriptions. Each API page links back to its original source so you can verify it.

What is a Bruno collection and how do I import one?

Bruno is an open-source, Git-friendly API client that stores collections as plain files on disk. To use an API from this catalog, download its collection ZIP, unzip it, open Bruno, choose Open Collection, and select the folder. Then set the baseUrl variable and any credentials and start sending requests.

Can I get the raw OpenAPI file for an API?

Yes. Every API page has an OpenAPI spec (JSON) link, and the same document is available by appending /openapi.json to the API's URL, for example https://openapicatalog.com/apis/your-api/openapi.json.

Are the APIs free to use?

The catalog itself is free. Each API is owned by its provider and has its own terms, pricing, and authentication requirements. The Source link on every API page points to the provider or repository where those terms are published.

How are APIs categorized?

Each API is tagged with one or more categories such as Cloud & Infrastructure, Payments, or Developer Tools, based on metadata from APIs.guru and keywords in the spec and repository. Category pages list every API on a topic, ranked by GitHub stars.

Is there a machine-readable index for AI assistants and crawlers?

Yes. /llms.txt gives a short overview with category links and popular APIs, /llms-full.txt lists every API with a one-line description, and /sitemap.xml lists every page. The site also publishes schema.org structured data on every API and category page.

Note: This is an independent project and is not officially affiliated with Bruno or APIs.guru. All OpenAPI specifications are sourced from public repositories and catalogs.
